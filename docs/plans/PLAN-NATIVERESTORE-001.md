## 2. Classification of the tracked modifications and the injected header (step 3, decided here)

Observation, per file, with the disposition this plan proposes:

1. Hosted `CLK_INC` pause/stop checkpoint (`c64cpusc.c`, `mainc64cpu.c`, `mainviccpu.c`, `vic20cpu.c`): observation and control logic. Rehomed: the clock gate (`clock-gate.c`, `gate-observer.c`, `clock-observer.c`, `clock-observer-x64sc.c`) pauses at every cycle boundary through `--wrap=vic_cycle` and `--wrap=vicii_cycle` without a source change. Disposition: reject from the oracle.
2. Per-cycle register export and re-import (`EXPORT_REGISTERS()` / `IMPORT_REGISTERS()` in the same macro): observation of CPU-internal state. The registers are locals of the interpreter loop (`6510core.c`), unreachable by link-time wrapping; the observer reports the bus instead (address, data, kind, clock, interrupt mask, BA, stolen, per half-cycle). Disposition: reject from the oracle; Phase E item 1 moves the C64 comparison from registers to the observer field set (already the handoff's wording), and register parity at instruction boundaries, if still wanted, is a Phase E question for Payton, not a reason to keep the patch.
3. Bootstrap from a host-provided register file (`vice_shim_take_bootstrap_maincpu`): resume-from-host-state. Disposition: reject from the oracle; resume is the VSF path (`PLAN-VSFLOCKSTEP-001`, native `.vsf` as the canonical snapshot), where the external `MAINCPU` adapter (S5) is the only compatibility path.
4. Snapshot module relaxations (`drive-snapshot.c`, `drivecpu.c`, `drivecpu65c02.c`): legacy snapshot normalization. Disposition: already rehomed in the external VSF adapter (199 green cases); reject from the oracle. Step D0 diffs the three hunks against the adapter's covered cases and lists any hunk the adapter does not cover as a finding before the revert.
5. SID and VIC sound probes (`resid/filter8580new.h`, `resid/sid.h`, `sid/resid.cc`, `vic20sound.c/.h`; `native/patches/s9-filter-probe.patch`): observation of chip internals for the S9 filter work. 6. Injected `vice/src/vice-shim-runtime.h` and `.vice-shim-configure-flags` (LEGION2 only): injected source and configuration for the shim. Disposition: generated or injected, preserved in the Phase 0 receipt; excluded, not deleted (D4), until Payton clears deletion.
