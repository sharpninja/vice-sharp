2. Old tile binding used RomTile instead of main's GameGroup. Retain group selection, subtitle/variant count and primary launch target; add wrapping cover tiles.

Initial disposal on detachment was corrected after R1: retain the loader across tab switches; dispose on reconnect/window close.
5. Old automatic scan bypassed main's remembered-server behavior. Keep TryAutoConnectAsync, starting on visual attachment rather than constructing a detached test view.
6. Old collections selection changed a value without showing members. Reuse the existing Lists tab and member-loading path; retain the separate CSDb tab. Catch user-visible collection operation errors instead of allowing async event exceptions to escape.
7. Existing detail requests could complete out of order. A per-request generation and gateway identity prevent stale success/error publication. The view also rejects detail metadata that does not match the selected group.
